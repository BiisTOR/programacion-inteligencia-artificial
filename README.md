# Programación de Inteligencia Artificial

Repositorio con las tareas del módulo **Programación de Inteligencia Artificial** del Curso de Especialización en Inteligencia Artificial y Big Data (CIDEAD, curso 2026-27).

## Tarea 1: Habilitando un perfil en el ecosistema de desarrollo de IA

En esta primera tarea se pide crear una cuenta en GitHub y un primer repositorio que incluya este archivo **README.md**, escrito con lenguaje de marcado (Markdown) y con una breve explicación de la tarea, y un programa sencillo **Hola Mundo** en Python: [`hola_mundo.py`](hola_mundo.py).

Para ejecutarlo:

```bash
python hola_mundo.py
```

Resultado esperado:

```
Hola Mundo
```

En las próximas tareas del módulo se irán añadiendo nuevas carpetas a este repositorio.
